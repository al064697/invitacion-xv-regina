# Invitación XV Años - Regina Sofia

Invitación digital elegante y animada para la celebración de XV años de Regina Sofia.

## 🎉 Evento

- **Fecha**: 4 de Enero, 2026
- **Ceremonia Religiosa**: 6:00 PM
- **Recepción**: 8:00 PM

## ✨ Características

- Diseño responsive (móvil, tablet, desktop)
- Animaciones premium y efectos sofisticados
- Contador regresivo en tiempo real
- Integración con Google Maps
- Confirmación vía WhatsApp
- Botón para agregar al calendario
- Optimizado para todos los navegadores (Safari, Chrome, Firefox, Edge)

## 🚀 Tecnologías

- HTML5

- JavaScript (Vanilla)
- Google Fonts (Playfair Display, Montserrat, Great Vibes)
